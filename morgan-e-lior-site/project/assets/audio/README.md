# Música de fundo — como ativar

1. Coloca o ficheiro de áudio nesta pasta com o nome exato `trilha.mp3`.
   (Formato `.mp3`, de preferência com licença própria ou livre de direitos.)

2. Não precisas de mexer em nenhum código — `index.html` já aponta para
   `assets/audio/trilha.mp3`.

3. Se não colocares o ficheiro, o player continua visível mas mostra um
   aviso ao tentar tocar — o resto do site funciona normalmente.
